連接 Google Sheet

登入 Google 後，直接在此 GitHub 網頁讀取私人試算表。資料與存取權杖只留在本頁記憶體，不會寫入 GitHub。

首次設定需在 Google Cloud 啟用 Sheets API，建立「網頁應用程式」OAuth 用戶端，授權 JavaScript 來源設為 https://yijenfeng.github.io。讀取權限為唯讀試算表；Google 授權範圍涵蓋帳號可讀的試算表，本程式僅要求下方指定檔案。
